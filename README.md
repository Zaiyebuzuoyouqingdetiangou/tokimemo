# 心迹回廊 · Hearttrace

为 SillyTavern 角色聊天准备的“回忆档案室”。把一段聊天整理成带编号的记忆档案（M001、M002……），再从档案出发生成相簿、ADV 事件、他的房间、来信、结局与后日谈等恋爱养成风格的番外内容。灵感来自《ときめきメモリアル Girl’s Side》系列，只借用玩法概念，不使用任何原作素材（见 [NOTICE](./NOTICE.md)）。

独立的第三方扩展，与兔子镜无依赖、无共享运行时。

当前版本：**1.0.19 / r84.236-framing-paths**　最低 SillyTavern 版本：**1.13.0**（以 `manifest.json` 为准）

本版补齐上一版遗漏的特写取景路径：完整图、单镜替换图、抠图回退和旧版手书均完整保留局部构图，导出同步等待背景就绪。保留原有图片编辑、定段定句、片头片尾、抠图和按需加载。详见 [本版说明](./RELEASE-1.0.19.md)。

## 安装与更新

在 SillyTavern 的“扩展 → 安装扩展”里填入：

`https://github.com/Zaiyebuzuoyouqingdetiangou/tokimemo`

更新时只覆盖插件代码，聊天、档案、图片和本机数据都会保留。更新前请等正在进行的生成结束；页面里尚未保存的成果可以先导出。刷新页面后，在设置页确认版本号。

支持电脑浏览器、手机浏览器里的云酒馆，以及 TT。

## 快速上手

1. 打开扩展菜单里的“心迹回廊”，在**设置**里配置独立 API：可以一键引用 Connection Manager 的连接，也可以手动填写 OpenAI 兼容地址。温度、最大输出都由你自己决定。
2. 切到**当前档案**，为当前聊天创建档案。之后可以手动增量更新，也可以在设置里开启按楼层自动同步。
3. 切到**内容**，按分组挑一页生成或浏览。每一页都单独生成、单独保存，某一页失败不会影响其他页。

## 功能一览

**回忆**：回忆相簿（CG 与共同回忆）、ADV EVENT、两个人的陈列柜、回忆收集率（新）

**生活**：他的房间（随现实时间流动，可翻找物品、查看私人终端）、你的邮箱、他的出行路线、两个人的日历、手帐、他在等你（新）

**互动**：角色互动（四季小剧场、Voice Drama）、基础语言、萤火虫栖息地、日常一格、人际庭园、成就库、角色印象曲、镜译语音通话

**番外**：ENDING 与后日谈、蝴蝶效应、前世今生、时空回响、睡前故事

所有声称“过去已经发生”的内容都必须指向档案里真实的记忆编号；角色卡、Persona 和世界书只负责人设与世界观。

## 新增：回忆收集率 · 朋友情报 · 他在等你

- **回忆收集率**（内容 → 回忆）：统计相簿 CG、ADV 正文、成就、ENDING 路线的点亮比例，萤火虫、来信、睡前故事等可以一直追加的内容只记数量。点“查看毕业结算”会看到片尾字幕式的回顾。全部在本地统计，不发请求。
- **朋友情报**（人际庭园 → 点开一个人 → “向 TA 打听他的事”）：请这个人用自己的口吻讲“他提起你的样子”“TA 看到的他”和一句悄悄话。前两段附档案编号，对不上档案的部分会标为“生活设定”。打听记录按聊天保存。
- **他在等你**（内容 → 生活，默认关闭）：开启后，可以看看你离开的这几天里他的样子。“你不在的时候”是一张九宫格：点开每个地方可以读到此刻的他、细节和心里话；有两处上了锁，四位密码藏在其他房间的细节里。你还可以让一封没寄出的信出现在邮箱，让一个生活片段出现在他的房间；之后你一回到聊天，这些痕迹就不再显示，但记录仍保留在“他在等你”里。关闭时，内容目录里的卡片会变成半透明。

这三项都不写入正式档案，也不改变其他页面的已有内容。生成永远由你点击触发，沿用你设置的 API、温度和输出上限。

## 新增：印象曲做成 MV（手书 / 视频）

在角色印象曲的歌曲页点“做成 MV”。先写一张分镜表（1 次文字请求），再选择：

- **手书**（推荐）：插件为每一镜画一张手绘风的图，在剪辑台里设置镜头怎么动、怎么切，放入你从 Suno 下载的歌，边听边在每段开头点一下对好时间，就能预览并导出视频。设备不能直接导出时，可用全屏录屏模式配合手机录屏。
- **视频**（进阶）：每一镜给出第一张图和中文或英文描述，按步骤到视频工具里“图生视频”，最后下载镜头时间表和字幕文件，在剪辑 App 里拼起来。

你可以选择露脸出镜、只拍背影或手，或者不出镜。生图次数由你决定，按钮上会写明。也可以用自己的图代替某一镜。放入的歌曲和自己的图只保存在这台设备的浏览器里，不会上传。

## 数据保存

- 档案与生成内容保存在各自聊天的 metadata 中（压缩存储），另有本机备份。
- 插件升级不等于档案升级：只有你主动更新档案，才会产生新的档案版本。
- 朋友情报与他在等你的数据按聊天窗口分开保存。生成完成时你如果已经切到别的聊天，结果会先留在本机，回到原聊天时自动合并。
