# 心迹回廊 1.0.25

SillyTavern 角色聊天扩展：整理回忆档案，创作相簿、剧情、印象曲和手书。

## 本次更新

- 新增了更新日志板块，感谢@nancyindaeyo的更新。设置标题旁可查看说明、检查当前分支更新。
- 分镜生成、补写和单镜改写优先使用流式接收，减少等待完整回复的情况；不减提示词、不降最大输出、不偷偷重试。明确设置了完整响应的连接仍沿用该设置。
- 图片编辑改为大画布：手机默认收起工具，点选格／裁切／修边再展开，随时可收起；PC 宽窗口使用双栏。底部“撤销、保存修改、保存并下一镜”常驻，保存按钮突出显示。收起工具不会把已放大的图片再放大，也不会丢失修改。
- 修复“移动画布后选擦除却没反应”；笔刷带大小数字和圆形预览，缩放显示百分比，点“看全图”复位。滑条改为细轨道，裁切后自动显示完整选区，保存等待时仍能返回。
- MV 待保存结果支持单条／全部清除；“更多／歌曲／导出”面板固定关闭区、独立滚动，不删除已保存作品。
- 智绘姬分镜请求使用剪辑台的精确画幅；修正贴边抠图的手臂与身体断口悬空。原图、特写完整入画、手动选格保留。
- 手书只用一个音乐入口、一个播放进度；加入 MP4／MOV／M4V 录屏音源试用，导入失败保留原音乐。
- 保留图片编辑、裁切修边、片头片尾、定段定句、字幕、导出及暂存恢复。只对表情卡拍默认抠图，其他类型保留完整分镜背景。

503／524 来自模型服务或代理，流式接收不能保证消除它们。若渠道不支持流式，可在设置的高级生成参数中选择“使用完整响应”。尚未完成 PC、iPhone、TT 真机验收及真实 API 复测；录屏音源的播放、同步、有声导出和 Suno 链接仍需实际验证。
