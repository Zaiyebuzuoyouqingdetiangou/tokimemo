# 心跳回忆 0.8.1

独立 SillyTavern 扩展。与兔子镜无依赖、无共享运行时。

## 专用 API

0.8.1 不提供“跟随当前 API”。所有档案整理、CG、ADV、蝴蝶效应、房间蓝图与每日生活时间线都固定通过一个 **SillyTavern Connection Manager Profile** 生成。

设置里可以：

- **从酒馆当前连接一键导入**：如果酒馆当前已经选中 Connection Manager Profile，心跳回忆直接引用它；否则插件读取当前连接的 API 类型、Server URL、Model、Preset、Instruct/Proxy 等必要字段，并读取当前 Secret 的 **Secret ID**，创建一个“心跳回忆 · …”专用 Profile。
- **手动选择已有 Profile**：从 Connection Manager 已保存的可用配置中选择。

一键导入不会读取、显示、复制或保存 API Key 明文。API Key 仍由 SillyTavern Secrets 管理；心跳回忆只保存 Profile ID。

生成 Prompt 也不会直接带入当前完整聊天。过去发生过什么只来自用户最后一次手动创建/更新的聊天档案；角色卡和通过档案摘要 dry-run 激活的世界书只用于保持设定一致性。

## 聊天档案

每个聊天窗口各自拥有独立档案：

- 第一次由用户手动“创建聊天档案”。
- 后续聊天不会自动进入档案。
- 只有用户主动点“更新档案”，新增聊天才会被重新整理、命名、总结。
- 所有声称“已经发生过”的 CG / ADV / 回忆 / 与用户有关的房间痕迹都必须引用真实 `sourceMemoryIds`，并通过对应记忆 `anchors/title` 的 `sourceMemoryAnchor` 证据校验；只猜一个存在的 ID 不够。

## 功能

- **蝴蝶效应**：从真实档案节点向外推演平行时空。
- **回忆相簿**：已解锁 CG + 基于已有关系的未来期许。
- **CG / ADV 回放**：事件索引先生成，长 ADV 按需生成并缓存。
- **他的房间**：按角色生活方式生成 2～8 个私人空间，并随现实时间运行每日生活时间线。

## 他的房间：时间流动

房间分为两层数据：

1. **空间蓝图**：卧室、客厅、工作室、营帐、船舱、实验室等长期结构，只在首次生成、档案版本变化或手动重新生成时更新。
2. **今日生活时间线**：每天生成 8～14 个生活节点；之后本地时钟只负责在已经生成好的节点间切换，不会每几十秒请求 API。

每日节点可改变：

- {{char}} 当前所在空间；
- 活动与短台词；
- 环境光线、窗户/窗帘、整洁度、桌面用途；
- 0～3 个当天临时生活物件；
- 普通生活痕迹。

与 {{user}} 有关的旧痕迹仍必须引用当前手动档案中的 `sourceMemoryIds`，并提供可在被引用记忆中验证的 `sourceMemoryAnchor`；不会因为时间流动而凭空产生共同过去。

## Token / 请求频率

- 创建/更新聊天档案：按聊天文本分块整理；单块生成输出封顶约 4k。
- 相簿/蝴蝶效应最高约 8k 输出封顶；CG 事件索引约 4k；首次生成后缓存。
- 长 ADV：点哪篇才生成哪篇，单篇最高约 8k，之后缓存。
- 房间空间蓝图/今日生活：单次最高约 6k；空间蓝图只在首次/档案版本变化时生成。
- 今日生活：默认每天首次打开房间时最多自动生成一次；如果当天自动生成失败，会落地本地基础作息并熔断当天自动重试，只允许用户手动点“更新今日生活”再次尝试；之后只走本地时钟。

“最大输出”控制单次模型输出上限，不代表每次一定消耗这么多 Token。0.8.1 另外增加输入侧安全预算：普通生成只抽取最多 48 条均匀覆盖时间线的档案记忆并压缩字段，最终发送前再以约 32,000 input tokens / 96,000 字符为硬上限；超限会在发送前停止，不会交给 API。档案分块整理会复用同一份角色卡/世界书 envelope。

## 0.8.1 安全修复

- 修复 `isPlaceholderText` 缺失导致“今日生活”在正常临时物件输出下抛 `ReferenceError`。
- 修复每日生活生成失败后 30 秒定时器无限静默重试；失败后当天自动熔断并使用本地 fallback。
- 所有持久化 session 增加 `chatId + archiveRevision` 双重绑定；API 返回前后校验当前聊天，跨聊天迟到响应直接丢弃。
- 切换聊天或禁用扩展时主动 abort 当前模型请求；档案整理中切聊天不会再显示成功或写入错误对象。
- 不再对完整 Prompt 调用 SillyTavern `substituteParams`；只本地替换 `{{char}} / {{user}}`，其余 `{{...}}` 宏全部中和，未归档消息/输入框/persona/变量不会经宏展开混入生成。
- `sourceMemoryIds` 增加语义证据锚点校验，防止只猜 `M001` 等有效 ID 就把脑补往事伪装成真实记忆。
- 新增输入 Token/字符预算和档案 Prompt 压缩；超限在请求发送前失败关闭。
