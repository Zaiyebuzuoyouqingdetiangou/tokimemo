# 心迹回廊 1.0.25

SillyTavern 角色聊天扩展：整理回忆档案，创作相簿、剧情、印象曲和手书。

## 本次更新

- 新增了更新日志板块，感谢@nancyindaeyo的更新。可在设置标题旁查看更新说明、检查当前分支的更新。
- 待保存的 MV 结果支持单条清除、全部清除；素材库中默认收起，清除只影响暂存结果。
- 修正“更多／歌曲／导出”面板被遮挡的问题，关闭按钮固定，内容独立滚动；可点遮罩或按 Esc 关闭。
- 智绘姬的分镜请求改用剪辑台的 16:9／9:16 精确比例；修正抠图贴边素材的手臂、身体断口悬在舞台内的问题。已有原图保留。
- 正式手书剪辑台采用新布局：预览、分镜、定段定句、全片样式分区操作；图片编辑支持保存并下一镜。
- 针对手机上预览被压成细条、工具区过小的问题，修正主题尺寸覆盖，为画面和工具保留可用高度；屏幕不足时可滚动。待保存结果放入“更多”的数量提示，仍可逐项恢复。
- 统一手书音乐入口：没有音源时显示“导入音乐”，导入后显示当前文件名，点开即可更换或移除。
- 加入录屏音源试用：选择有声音的 MP4、MOV 或 M4V，和手书共用播放进度。录屏画面不会加入分镜；读取失败时保留原音乐。
- 保留图片编辑、选单格、裁切修边、片头片尾、定段定句、字幕、导出和暂存恢复，不改生成提示词。

界面按 PC、手机和 TT 共用路径适配，尚未完成真机复测。不同生图渠道能否返回精确比例仍需实际出图确认；录屏音源的真实播放、同步、有声导出也需实测。Suno 链接仍为试验功能，不保证可导入。

## 安装与更新

扩展地址：`https://github.com/Zaiyebuzuoyouqingdetiangou/tokimemo`

支持 SillyTavern 1.13.0 及以上。覆盖插件代码后重新打开酒馆，确认版本为 **1.0.25**；已安装过同号包也要完整刷新页面。不会清除已有聊天、档案、分镜和图片，更新前请先保存当前编辑。

详细记录见 [更新日志](./CHANGELOG.md)，使用范围见 [许可证](./LICENSE)。安装包不含 GitHub 工作流。
