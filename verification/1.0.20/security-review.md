# 源码差异自查

本轮为代码差异与专项检查；没有声称运行独立安全扫描产品。

- 请求仅在主动点击或回车导入时发生；HTTPS，HTTP 仅解析确认的 loopback；拒绝带用户名密码及非网页协议的 URL。
- 请求使用 credentials: omit、no-referrer、CORS 与可取消信号；不读取宿主密钥、Cookie 或外部插件数据。
- 网页只提取公开音频标签；不执行脚本，不导入模块，不调用私有端点，不拼接猜测的 CDN 文件地址。
- 远程标题与输入值经过现有 HTML 转义；原始响应正文、未知错误详情和签名链接不写进 toast 或作品存档。
- Blob 通过元数据验证后才提交。取消、失败、超时、切换歌曲／聊天、歌曲内容变化的专项已执行。
- 同源 Blob 供预览与录制使用，不将跨域元素能播放误当作声音可导出。
- 远程网站的 CORS、访问权限与音源发布方式仍可能阻止导入；本实现不会绕过这些限制。
