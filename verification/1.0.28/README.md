## 改动与边界

- 收起剪辑台外层重复导航，提供明确返回入口；离开剪辑台恢复原导航。

- 图片编辑缩放栏移到画布下方。像素编辑、撤销、提示词与保存实现未改变。
- 非 UI 源文件逐字节比较通过；仅 releaseNotes 更新本次说明、selfUpdater 更新安装版本号。不改生成预算、流式通道、请求次数、模型条件、数量上限或存储约束。
- README 只保留更新日志模块致谢及本次变动；运行包更新说明由同一 README 构建，离线读取不调用远程历史。

## 复现方式与未验证项

在项目根目录设置 `TEST_ROOT=.`，使用 `node --experimental-vm-modules --test` 运行 `tools/verification/*-regression.mjs`。完整检查按文件名排序分为 18/18/18 三批，各批 `--test-concurrency=4`。独立版本对照需要把 `BASELINE_ROOT` 指向解压的 1.0.27 项目根目录。

构建：`BASELINE_ROOT=<1.0.27 根目录> python3 tools/verification/build.py .`。打包：`python3 tools/verification/package.py . <输出 ZIP>`。打包器核验版本、路径、CRC、逐文件字节一致，并排除工作流及版本控制目录。

这些检查使用真实构建代码、受控 DOM/媒体/存储替身及原生 Canvas，不等同于浏览器实际布局或 iPhone／TT 验收。尚未执行真实设备触控、真实音视频导出或真实服务商生成；没有为测试发起付费生成。
