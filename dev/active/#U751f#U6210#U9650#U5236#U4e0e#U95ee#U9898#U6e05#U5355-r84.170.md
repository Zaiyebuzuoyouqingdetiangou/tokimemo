## 1. 已修：图片在续写 / 完成时被覆盖（r84.170）
`core/cacheGenerationDrafts.js` 的 `preserveProgressLocalState` 只保留 `cgImage`，没有保留按位置存图的 `visual` / `visuals` / `previousCgVisuals` / `fireflyVisual`。前世卷宗、睡前故事章节、蝴蝶节点、结局分镜、萤火虫的图，如果是在任务「未完成」时画的，下一步续写或正式完成时被整份覆盖。用户看到的是「画过的图重启后没了」。

## 2. 待议：前世今生里会让整步生成失败的文字检查（modes/pastLives.js）
这些检查一旦命中就 `throw`，整步请求作废、要重新花钱：
- 第 42 行 `presentText`：`narrativeClaimsSharedHistory` 和一条正则（「今生|现实|此生」后 16 字内出现「已经应验 / 确实发生 / 命中注定」等）。模型写一句抒情就可能命中。
- 第 43 行：`presentRelationshipAllows` 判定今生称呼超出当前关系。
- 第 34 行：番外里出现第三人的恋爱婚姻。
- 第 130 行：今生记忆回响必须逐字出自所引 Mxxx，差一个字整步失败。
- 第 138 行：未来回响必须写成可能 / 愿望 / 假设。
- 第 144 行：旁批引用了不存在的线索。
建议方向：不再让整步失败。只影响一条回响 / 旁批的，丢掉那一条并在任务中心提示；整段文字的，保留正文，只把命中的那一句去掉或标注。逐字引用对不上时，退为不显示「今生真实记忆」标签，而不是作废。
