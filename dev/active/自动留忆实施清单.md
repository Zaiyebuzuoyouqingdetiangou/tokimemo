# 自动留忆实施清单

> 本文是施工顺序和验收 List，不重复解释产品原因。  
> 产品逻辑见 [自动留忆与成就存档方案.md](./自动留忆与成就存档方案.md)，模块请求链见 [自动留忆模块生成合同.md](./自动留忆模块生成合同.md)。

## 1. AI 开工规则

- 严格按 R0 → R8 推进；没有通过当前轮完成门槛，不进入下一轮。
- 每轮保持现有手动生成可用。
- 模块只能在对应适配完成后加入自动候选。
- 目录、索引和 plan 不是完整成果。
- 自动任务必须跑完冻结计划，才生成一个成就和信封。
- 生产状态以聊天 metadata 为主档，IndexedDB 只作恢复备份。
- 修改实现前重新核对相关真实代码；本文文件名是建议落点，不替代代码事实。

## 2. 总依赖

```text
R0 数据合同
└─ R1 启用向导
└─ R2 旧调度收敛
   └─ R3 统一调度器
      └─ R4 生成壳

                     └─ R6 揭晓入口
                        └─ R7 成就回看与跳楼
                           └─ R8 TT、锁与全量验收
```

R4 可以和 R5a 并行开发，但 R5a 正式验收必须使用 R4 的完整状态。
