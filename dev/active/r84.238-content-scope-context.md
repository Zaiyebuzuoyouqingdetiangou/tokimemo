# 相簿 / 剧情事件选材修复

## 任务与基线

用户确认“那你修一下吧”：在相簿及 ADV 的首次和追加生成中提供档案范围、逐条勾选；默认继续补充，避免漏选材料，不增加创作模板、配额或自动批次。

唯一项目来源仍为用户上传的 1.0.19 ZIP；本轮从已交付且已核对 SHA-256 的 1.0.20 完整包继续，不取 GitHub main。

## 根因与决定

旧路径首次给模型 48 条，却由 stampIncrementalCoverage 在 previous 为空时记录全档 500 条已覆盖。截图的具体存档未提供，不能把此复现称为该存档验收。
新 core/contentSelection.js 仅接入 album / adv。generationMeta.contentSelection 单独记实际提供的材料；不从旧全档标记推断已处理。旧作品来源作为已确认材料，其他旧进度保留不确定提示。
手动范围完整传入，无隐藏 48 / 64 / 240 抽样；自动沿用首次 48、后续 64 的单请求材料规模。用户点击才下一批，原 3～6 / 0～6 等写作规则不变。
恢复 operation.contentSelectionPlan 保存原始范围；旧付费草稿继续原提示词抽样，不偷换请求。关系扫描仍用完整档案；补共同回忆只补对白，不推进选材。
