# r84.214 对时间与夜间配色

## 合同

- 唯一基线：用户上传 `hearttrace-upload(20261001-153418).zip`，BUILD `0.99.99-r84.209-redraw-chunks`。
- 可观察结果：任一段落卡片可以选择对齐目标；大按钮记录该段，原有顺序打点、撤销、重开与音频播放不退化；MV 浅色／深色文字面板采用成对主题色。
- 不变量：歌曲、分镜、图片 Prompt 不变；不增加质量校验、生成限制、收费请求；上传包已有重画与分批逻辑不变；不改已存图片、歌词和已保存打点。
- 唯一生产逻辑改动文件：`src/ui/mvView.js`；另外更新入口构建身份、文档和编译 bundle。

## 根因与证据

原版顺序大按钮在模拟宿主可逐段前进；段落卡片是没有动作的 div，无法选择其他段落。新增 public action `select-section`，不跳音频也不写存储，只有点击打点按钮才保存。会话内保留撤销快照，重开／换歌时清空；旧档案无需迁移。

MV 局部歌词底色固定为浅米色，但全局主题会把文字改为夜间浅色。使用现有 `--rmt-paper-letter` 与 `--rmt-paper-letter-ink` 并通过 `--rmt-content-ink` 传给内部文字。同类 MV 提示面板改为主题色，不改全局皮肤或视频画布。
