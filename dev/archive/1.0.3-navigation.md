# r84.220 手书定位、逐层返回与相簿缩略图

基线：已交付 1.0.2-r84.219-mv-overlay-controls 完整 ZIP；SHA-256 85fdc409f7645a751dc7ed9c18c79c3fe7c40635a945fb222ecc3332a9b1e217。上一版与原数据均保留。

## 机制与范围

1. `src/ui/mvView.js` 的编辑器离开后重建构图页，没有保存打开前的滚动位置；短页面替换长页面会让浏览器裁剪 scrollTop。现在临时记录页面路径、图片锚点、滚动位置、折叠和横向缩略图状态。同页后台图片加载刷新也恢复位置。路径仅属于当前打开的歌曲，不写入存储。
2. 原有工具栏返回在模拟宿主下可以分派到正确的 MV 页面，但没有恢复父页位置。不能据此认定已复现用户真机上的所有“返回无响应”。现在另提供页面内返回按钮，并用实际打开路径逐层返回；对时间完成回剪辑台不会形成返回循环。素材编辑仍保护草稿和迟到结果，补上关闭回调的编辑器序号检查。
3. `src/ui/albumView.js` 的兔子 summary 位于 `data-rmt-album-id` 卡片内，点击冒泡被 albumSelect 捕获后重建列表，菜单立即消失。本轮按用户要求删除卡片菜单，而不是更改其他模块的公共图片菜单。图片设置、夹进手帐保留在共同回忆详情；详情加入返回入口并按会话对象保存列表位置。
4. `src/ui/overlayCore.js` 的相簿返回分支调用上述详情关闭函数。其他事件分派顺序不变。

修改边界：上述 3 个生产源文件、版本身份、确定性 bundle、说明和新增验证文件。不改 MV 领域数据、任何 Prompt、已有测试、剪辑与导出渲染、生成请求、数据 schema、预算、上限或收费行为。没有发布到 GitHub。
