# 1.0.5 / r84.222 意象透明背景

基线：上一轮已交付 r84.221 完整 ZIP；SHA-256：f65e49f27c53b9aa8a5b8c8d6745aac08b428c738f47aee232f2998707541bbe。独立基线与候选，不写 GitHub。

## 需求与根因

用户反馈意象白底方块挡画面，要求修复。默认意象提示词要求 white background；drawMotif 在 layerImage 没有确认透明素材时直接回退 imageFor 原图，所以白底成为漂浮方块。

## 改动范围

extras/mvImageTools.js：新增意象专用像素处理，不修改人物用的 eraseEdgeWhite。真实透明图保留；一致白/蓝边缘经连通去底，外轮廓去底色边；封闭白色细节保留；空白、不规则边缘及读图失败不冒充成功。判定不用去白面积比例。播放装饰采用最大边 768 的工作栅格，原文件不改，不限制上传或生成尺寸；编辑器按原图处理。
ui/mvView.js：意象缓存、透明缩略图、异常时编辑入口；取消意象的不透明回退。预览与导出共用，生成/导入不同 URL 会取新的缓存。缓存只读图片，无自动存档、无模型请求。
ui/mvImageEditor.js：只在 motif 选项开启时预置透明工作稿，并提供去白/蓝背景。保存时原图保留；人物、背景、其他图片不自动处理。编辑器仍先挂出操作界面，再读图，不等待图像解码才允许改提示词。
extras/mv.js：仅 defaultAssetPrompt 的 motif 分支调用新 motifRecipe；白色/雪花/冰霜等用对比蓝底，其余白底；从默认描述中移除冲突的白/透明/简单背景标签。用户完整自定义提示词绕过该分支，原样返回。

## 验证合同

新增 mv-motif-regression.mjs，14 项真实 bundle/原生 Canvas/PNG 测试，覆盖透明像素、白色前景、白色内孔、反锯齿底色、旧白底兼容、原图不动、意象开关、无前景不叠加、读像素失败、换图缓存、编辑保存 PNG、蓝底撤销、预览导出同源与自定义 Prompt 原样。

申报唯一旧夹具变更：mv-overlays-regression.mjs 原来用纯不透明的 13×13 绿方块测试装饰开关；本轮要求不再叠加不透明方块，现把该测试图改为有 3 像素透明边缘的绿色意象。所有原断言、其他尺寸测试图均不变。新增反向测试明确检验不透明背景不得回退叠加。验收脚本逐字检查仅该夹具行改变；基线运行其原始文件，候选运行修正后的真实透明夹具。其余旧回归文件逐字不变。

Prompt 比对：171 个原函数逐字不变；defaultAssetPrompt 仅意象 return 分支不同，其余分支逐字核对。新增 motifRecipe 逻辑另有公开 assetPrompt 行为测试及完整源码补丁；不宣称所有 Prompt 零变动。
