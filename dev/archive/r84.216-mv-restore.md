# r84.216 分镜功能恢复与成果保护

构建：`0.99.99-r84.216-mv-restore-safe-continue`

## 基线与范围

- 基线为已交付 r84.215 `hearttrace-upload.zip`，SHA-256：`7417583122db19fef6f8adfb3703027181aa984390a1c6f50d76a5e0f07e4639`。
- r84.213 只作为恢复 r84.209–213 已有功能的参考。r84.215 中的重画、歌词切批、对时间、夜间模式、写歌与保存修复保留。
- 用户授权恢复分镜类型／歌曲推荐／多人适配，并修复画图时自动再次分镜、覆盖旧内容。没有修改角色印象曲、睡前故事或其他玩法的创作 Prompt；没有 GitHub 写入。

## 根因与修复

1. 原 UI 在第一批分镜保存并进入构图页后自动循环续写，最多又发 20 批；回调还会读取可变的当前歌曲。现在初次生成和继续按钮各请求一批，后续由用户点击；回调绑定原聊天、原歌曲与页面打开序号。
2. 原续写将请求开始时的整个 record 快照当作新分镜保存，覆盖期间产生的 groups 图片；旧 story 指纹又没有包含 groups。现在续写只生成 append patch，并与保存时的最新记录合并。已有镜头、图片、打点、衣着、制作／导出范围不被替换。
3. 显式重新分镜仍可使用。若期间已有图片或相关编辑，迟到结果暂存，不覆盖。新分镜有独立版本标识，旧画图回调不能落到重建后同名的 G1/D1。分镜单飞锁保持至异步保存结束。
4. 「画这一组」原来会继承 dispose 的 stopAll=true。统一使用绑定原目标的绘制队列，每次主动启动清理停止标志，离开、换歌或同页替换分镜后不继续发送原队列的图片请求；期间手动补好的图片会跳过。保留单图换随机种子与整组共享新种子。
5. 恢复类型选择、可解释的歌曲推荐、逐人外貌／衣着、世界书条目选择、逐镜人物绑定。恢复缺失分镜补写、相对段落索引兼容、片段导出与宿主错误正文识别。普通单人卡仍直接生成，不弹强制选人流程。
6. 保留旧批次素材复用。可以在后续段落引用已画 group/diff；混合新旧构图时编号不会碰撞，复用镜头不复制或清空原素材。

## 兼容和边界

- 不新增歌曲、人数、构图、差分、背景或全曲段落总量上限。恢复 r215 分支合并时漏掉的修复：不再截断到 8 组／5 差分／2 背景。
- 仍使用 r215 已有的约 10 句歌词切批策略，一段不拆坏；它是单次请求大小，不是整首限制。移除自动 20 轮循环。
- 不新增选人、填外貌、选类型的生成门槛，不改输出 token、输入预算、温度或服务超时设置。真实上游 524 仍可能发生，只修复错误分类。
- 旧 r215 待保存图片可仅保存恢复。旧分镜暂存若只有不足以校验 groups 的指纹，且当前已有图片，不自动覆盖；原图与付费返回内容均保留，可导出。不是把不确定的旧快照硬写进当前成果。
- 写歌文件 `src/modes/themeSong.js` 与 r215 字节一致。尾声对白没有在本轮另加或移除规则。
- 旧聊天、歌曲和图片不会在升级时批量重生成或迁移重绘。已经被旧版本覆盖且无历史副本的图片，补丁不能凭空恢复。

## 验证口径

- 所有原有回归源码与断言保持不变；对比基线及候选，不以删测或改预期凑全绿。
- 80 项由分支遗漏造成的旧失败恢复通过。另加 18 项请求次数、异步覆盖、队列隔离、种子、素材复用和实际 r215 journal 升级测试。
- 两项原有失败保留并单列：旧断言要求普通档案 revision 增长也拒绝 MV 保存，而现行要求是同歌同聊天可保存；另一项只接受英文 `no people`，现行空镜表达为 `no humans`。r215 的同歌保存用例与 12 种人物／外貌组合行为用例继续验证这两个实际要求。
- 本轮验证脚本检查所有 JS/MJS、实际 source/bundle 运行绑定、连续重建、全部 Prompt 函数哈希、完整差异及未改文件哈希；三轮记录在包外 evidence 中，最后一轮从最终 ZIP 新解压运行。
- 模拟宿主不等于手机实机。未执行真实 TT / iPhone、浏览器 DOM / CSS、付费文本／生图／Suno 或独立审查。日志如有失败保持原样。

## 使用位置

- 新歌：做成 MV → 第二步「分镜与出镜」→ 分镜类型。
- 旧歌：构图卡片／镜头清单 → 分镜类型；改变用于之后的分镜。
- 继续未完成段落：制作范围改为需要的段落或整首 → 继续分镜。画图不触发分镜请求。
- 导出片段：剪辑台 → 导出哪一段 → 已完成片段或自选起止段落。
- 安装：覆盖完整包后刷新；设置页核对完整 r84.216 构建号。无需卸载、删档或重做旧歌。
