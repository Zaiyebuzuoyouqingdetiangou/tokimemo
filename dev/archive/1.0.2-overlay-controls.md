# 1.0.2 / r84.219 播放遮挡修复

## 合同与基线

用户确认修复已复现的片尾越界遮挡、短镜头转场过长，并增加副歌关键词、漂浮装饰开关与可关闭的片尾时长。
唯一基线是已交付 `1.0.1-r84.218-mv-intro-duration` 完整包，SHA-256 `baca3bb7cc55cd955d137b32db03005a7dc0b9eb699377e12bba8f44e5ff7d31`。
原包及原目录保留，候选只改 `src/extras/mv.js`、`src/ui/mvView.js` 两个生产源文件，以及身份、构建产物、说明和新增验证工具。

## 根因与改动

1. 片尾此前只检查 `range.end - t < 2.5`，拖到片段结束之后的负值也满足条件。现在要求时间位于所选片段内，使用该曲的 `tegaki.outroSeconds`；默认 2.5 秒，0 关闭，实际时长不超过末镜头与片段交集的一半，短片尾按比例淡入。
2. 淡入／闪白以前固定 0.16–0.45 秒，可能遮掉很短镜头的大半。新旧 MV 的转场均取原时长与当前镜头时长四分之一的较小值；长镜头效果不变，镜头切点、拍点和歌词时间不变。原有副歌节拍闪光模板不改。
3. 副歌关键词原先独立于歌词显示条件。新增 `showKeyword`，缺省开启，但歌词“不显示”时也不绘制；重新显示歌词时恢复原选择。新增 `showMotif` 控制漂浮装饰，缺省开启。两项按歌曲保存，素材不删除，切换不生成。
4. 使用现有渲染入口，预览、全屏录制、导出一致；保留既有导出快照，录制中修改开关不会改变已开始的输出。

## 不变量与新增边界

- 任何 Prompt、生成请求、输入输出预算、角色／镜头数量和质量条件都不变；没有额外模型调用、生成前置条件或自动重画。
- 原图片、手动编辑、透明素材、提示词自定义、分镜、歌词、打点及存储格式不迁移、不覆盖。
- 新增边界仅限制遮挡显示时长：片尾最多占末镜头一半；转场最多占当前镜头四分之一。秒数字段仅接受有限非负值，非法输入保留旧设置；旧存档缺字段时沿用默认显示。
- UI 复用主题颜色和输入框，开关使用原生 checkbox 与 44px 标签触摸区域，不引入外部依赖或新浏览器 API。

## 定向证据

`mv-overlays-regression.mjs` 通过公开 UI 操作与原生 Canvas 像素复现：

- 30–90 秒片段的片尾不再遮住 100/110 秒的画面，片段之前也不出现片尾。
- 片尾时长可保存／重开／设置为 0，小数秒和非法值不破坏原数据。
- 0.2 秒末镜头先展示原画，再在后半淡回片尾；转场在新旧两种 MV 下均保留效果并及时结束。
- 正常长镜头仍保留淡入；隐藏歌词不残留关键词，两个开关可独立使用且不删除素材。
- 片段导出保存设置及时间轴；模拟 MediaRecorder 输出实际 Canvas 帧，与预览一致，录制快照不受中途修改影响。
